# 从阅读开始

这是用于人工验收的中文文章。**语义加粗**、*斜体*与 `inline code` 会同步到 Markdown，颜色与边框不会改动正文。

## 一个连续的编辑过程

> 文字由文章决定，设计由模板决定。

- 直接修改正文
- 使用工具调整内容与样式
- 保存后刷新，继续同一个项目

### 一段代码

```js
const article = '中文也能完整保留';
console.log(article);
```
