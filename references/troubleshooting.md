# 排错

- **打不开页面**：先 npm ci && npm run build，保持本地服务运行，使用终端的新认证 URL；端口冲突改 --port。不要打开旧 studio.html。
- **原文哈希不符**：source.md 在冻结后被改动，不能把已改文件当原文。恢复真实原文基准，检查 AI 是否误写；不要改清单哈希掩盖差异。
- **首次文字对照失败**：查看原文/结构稿差异片段，只修 structured.md。标题层级和加粗可变，标题字句不能被一律排除；新增概括性小标题是内容增加。明确授权改写时另行处理并确认，不假称原文不变。
- **没有原文对照记录**：直接导入没有提供 --source-md，不声称已证明 AI 结构化前后没改字。正式 Skill 流程先 --prepare-only 冻结，再带基准启动。
- **401 / 无法连接**：每次启动使用新的 #token URL，只支持本机 127.0.0.1，不分享令牌。
- **已有活跃页 / 409**：关闭其它编辑页再刷新。同项目不能起第二个服务；不要删除活动锁。
- **AI 版本冲突 / 复制期间内容变化**：重新读取当前状态；复制/导出期间有新编辑时重试即可，不需要重新校验原文。不要用磁盘快照覆盖活跃会话，不盲目重放未知结果。
- **保存失败**：保留页面、不刷新，检查权限、磁盘和连接，点击保存重试。只有已落盘内容能恢复。
- **图片缺失或外链不能导出**：资源必须能从项目读取，外链请换成本地图片；不会自动上传第三方。未引用资源不自动删除，以免误删。
- **复制失败**：请在支持 ClipboardItem 的 Chrome 或 Edge 中检查剪贴板权限，再重试复制当前版本；不存在“先重新校验”步骤。
- **微信粘贴图片/样式变化**：微信可能再次过滤内联 PNG 和 CSS，需人工检查，必要时在微信补图。本项目不会暗中上传图床。
- **编辑器与复制的样式不同**：这是渲染实现缺陷，不应要求用户切换发布预览规避。保留当前项目、模板和复现步骤，检查共享样式、字体继承、标记嵌套、列表与装饰的回归测试。
- **个人模板找不到**：确认使用的是当前 skill 的 `modules/templates/user-presets/<user-id>/`，只有 `publish` 后的 `preset.json` 会载入。用 `npm run preset:user -- check <user-id>` 查看 JSON 或 PNG 诊断，修复缺失资源或恢复该模板备份；无效的模板不会拦住其他项目，依赖该模板的项目会提示错误而不是悄悄换风格。
- **刷新后历史消失**：文章和视觉保存，撤销栈与光标不跨刷新恢复。换模板仍可在当前会话撤销。
